# ScamShield--AI-based-Multi-Modal-Phishing-detection-in-Everyday-Digital-Communication.
AI-based multimodal scam detection system for messages, URLs, images, and videos with multilingual support to identify potential online scams and protect users from digital fraud.
ScamShield – AI-Based Multi-Modal Phishing Detection

Project Overview

ScamShield is an AI-based multi-modal scam detection system designed to identify potential online scams and phishing attempts.

It analyzes messages, URLs, images, and videos to help users stay safe from digital fraud.

Features

- Message scam detection
- Suspicious URL analysis
- Image-based phishing detection
- Video analysis
- Multilingual support
- Customer care message checking
- Digital safety assistance

Technologies Used

- Python
- Flask
- OpenCV
- Pytesseract
- BeautifulSoup
- Requests
- HTML, CSS and JavaScript

Installation

Install the required dependencies:

pip install -r requirements.txt

Run the Project

python app.py

Open the local URL displayed in your terminal/browser.
